MNELIB::MNERawInfo captures the sampling frequency, channel list, calibration vector and the MNELIB::MNERawBufDef table reconstructed from a -raw.fif file - effectively the fields that the original MNE C tools stored next to the file handle. Provides quick metadata access without forcing callers to materialise a full FIFFLIB::FiffInfo.
