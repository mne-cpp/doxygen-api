Detailed Description

Describes the frames of a trace view as GpuFrame for any backend.

One pass clears to the background and draws one line strip per trace (shader "channeldata"), then the annotations, events and epoch markers with the per-second bands (shader "overlay" over a texture that spans overlay_prefetch() view widths on each side, so scrolling does not redraw it), then the crosshair, scalebars, ruler and annotation selection (shader "overlay" over a screen-sized texture). The builder keeps the vertex buffers, textures and pipelines in resources() and streams vertices through its TraceGeometry.

3.0.0
