Detailed Description

FIFF tag: 16-byte header (kind, type, size, next) plus payload, with typed decoders for every FIFFT_* type.

Holds the four header fields exactly as stored on disk and the raw payload bytes. Decoders convert the payload to the appropriate C++ representation: scalars via to_int / to_float / to_double, dense and sparse matrices via to_float_matrix / to_sparse_float_matrix, and the structured FIFF records into their class wrappers (to_fiff_id, to_coord_trans, to_ch_info, to_dig_point, to_dir_entry, ...). Used by FiffStream both for streaming reads and for assembling tags before write_tag.

FiffStream stream(QString(dir + "/sample_audvis-ave.fif").toStdU16String());
const bool opened = stream.open();
const std::vector<std::shared_ptr<FiffDirNode>> measNodes = stream.dirtree()->dir_tree_find(FIFFB_MEAS_INFO);
const std::optional<FiffTag> nchan = measNodes.front()->find_tag(stream, FIFF_NCHAN); // raw tag access
const FiffId fileId = stream.id();
stream.close();
