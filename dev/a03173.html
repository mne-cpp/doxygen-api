Detailed Description

Real-time FIR / IIR filtering of streaming MEG / EEG data blocks.

The functions in this header wrap mne::FilterKernel and the design back-ends so an incoming raw data file or live data block can be low-pass, high-pass, band-pass or notch-filtered in place with a single call. filterFile streams a mne::FiffRawData source through a user-designed kernel and writes the filtered output to a FIFF file, optionally filtering the channels in parallel on the global thread pool. All cutoff and transition values are specified in Hz — normalisation against the sampling rate happens inside the design call.
