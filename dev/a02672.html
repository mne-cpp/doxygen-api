mne::InvGammaMap implements the Gamma-MAP / sparse Bayesian learning (SBL) solver of Wipf & Rao, NeuroImage 44(3), 947-966 (2009). The algorithm models source amplitudes as Gaussians with per-source variance hyperparameters \(\gamma_{i}\) and uses an MacKay fixed-point update (as in mne.inverse_sparse.gamma_map) to re-estimate the \(\gamma\) vector from the data; sources whose \(\gamma_{i}\) collapses below threshold are pruned, leaving a sparse active set. Output is an mne::InvGammaMapResult carrying the mne::InvSourceEstimate, the surviving active-vertex list, the final \(\gamma\) vector, iteration count and residual norm.
