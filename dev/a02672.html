mne::MNEMeasData mirrors mneMeasDataRec from the original MNE C tooling. It bundles an mne::FiffInfo with a list of mne::MNEMeasDataSet entries (one per averaging condition) and the active projection / CTF compensation state. Kept verbatim so ported C utilities (mne_inverse_operator, mne_compute_raw_inverse, ...) continue to operate against the same in-memory schema.
