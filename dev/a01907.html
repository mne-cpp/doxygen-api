RtFiffRawView is the QTableView host that displays a rolling window of the live FiffStream through the model / delegate pair in helpers/. It owns the scrollbars, the marker / annotation machinery, the trigger-channel overlay and forwards mouse-driven channel selection / re-ordering events to the parent mne::viz::qt::ChannelDataView.
