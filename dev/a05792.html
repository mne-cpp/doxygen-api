Detailed Description

Set of FiffEvoked instances sharing one FiffInfo, plus channel-picking and compensation helpers.

The on-disk shape of a *-ave.fif: one FiffInfo and one FiffEvoked per FIFFB_EVOKED block (one per averaging condition). Conversion utilities pick channels and shift compensation state across the whole set in lock-step.

FiffEvokedSet evokedSet((dir + "/sample_audvis-ave.fif").toStdU16String()); // all conditions of an -ave.fif file
const FiffEvoked& leftAuditory = evokedSet.evoked[0];

Compute a grand average across multiple evoked data sets (mne.grand_average with interpolate_bads=False, drop_bads=True). For each category, channels marked bad in any set are dropped, the common channels are kept and the sets are combined with equal weights. nave is set to the number of sets and the comment to "Grand average (n = N)".

Returns
