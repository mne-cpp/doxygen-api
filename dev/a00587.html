Detailed Description

QRhi-based GPU-accelerated channel time-series renderer used by the modern raw browser.

ChannelRhiView is the QRhiWidget host of the Widgets-free mne::disp::ChannelRhiRenderer, which holds the view state, uploads channel data as vertex buffers, draws every visible trace and paints the crosshair, scalebar and ruler overlay in the same GPU pass. The widget forwards its input events and frames to the renderer and exposes the API used by mne::disp::ChannelDataView to push new samples, change scaling or update the visible window. Applications without Qt Widgets can use mne::disp::ChannelWindow instead.
