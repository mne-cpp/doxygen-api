Detailed Description

Minimum-norm source estimates of streaming data with an operator that follows the noise covariance.

The estimates equal mne::InvMinimumNorm::calculateInverse of an operator built by mne::MNEInverseOperator with the same covariance: one row per source, for a free-orientation forward solution either the component normal to the cortex or the magnitude of the current.

RtCov rtNoise(*rawInfo, 2.0); // noise covariance with a 2 s half-life
RtInvOp rtInvOp(*rawInfo, megFwd, {.method = InvEstimateMethod::dSPM}); // forward-only work happens on the first update
MatrixXd sources;
for (Index start = 0; start + 600 <= rawData.cols(); start += 600) { // 1 s blocks
const MatrixXd block = rawData.middleCols(start, 600);
rtNoise.update(block);
if (const auto noiseCov = rtNoise.covariance(); noiseCov && rtInvOp.update(*noiseCov)) {
sources = rtInvOp.apply(block); // dSPM of the normal component, one row per source
}
}
