Detailed Description

Reads XML documents into an element tree in standard C++, the counterpart of QXmlStreamReader.

parse_xml() checks that the document is well formed and returns its root element. Every element keeps its name as written, its attributes in document order, the character data directly inside it and its child elements. Comments, processing instructions and the document type declaration are skipped; CDATA sections and the predefined and numeric character references become text. Documents are UTF-8 or, if their declaration says so, ISO-8859-1. Namespaces are not resolved: declarations stay attributes and local_name() drops the prefix like QXmlStreamReader::name().
