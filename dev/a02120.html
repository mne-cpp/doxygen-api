Plot turns an Eigen::VectorXd into an axis-labelled 2-D line drawing inside a QWidget, mirroring the basic behaviour of MATLAB's plot(y) command. It is mainly used by demo applications and quick-look windows where a single-trace preview is sufficient; richer plots that need a real coordinate transform use mne::viz::qt::LinePlot or the application-side Qt Charts backends instead.
