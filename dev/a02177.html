Detailed Description

Implements the outlet worker: liblsl's UDP query and time-correction responders and its TCP data server.

The PIMPL class StreamOutletPrivate runs a dedicated std::thread that owns every socket, so no socket crosses threads. It answers discovery queries on the LSL discovery port 16571 (multicast groups, broadcast and localhost) and on its own UDP service port, which also answers time-correction requests. Its TCP server answers shortinfo and fullinfo requests and serves stream feeds of data protocol 1.10.

Pushed samples are encoded once, on the producing thread, into blocks whose first sample carries its timestamp; the worker appends each block to every inlet that is streaming, so an inlet always starts at a sample with an explicit timestamp.
