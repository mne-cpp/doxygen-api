Detailed Description

Toolkit-free state of a multimodal scene: the ordered scene-layer stack (MRI slice, BEM, cortex, sensors, dipoles, networks, overlays).

SceneState composes the brain view primitives into a single depth-sorted layer stack so the GUI shell does not need to know the per-modality render order. Each mne::viz::SceneLayer carries its renderable, a sort key and a visibility flag; the controller iterates layers in order and issues the corresponding draw calls.

It also routes pick events from mne::viz::qt::RayPicker through every layer and returns a uniform mne::viz::PickResult to the host, hiding the per-primitive intersection logic.
