Detailed Description

The sweeping window of a real-time raw-data view: new samples overwrite the oldest from the left.

Holds a raw and a filtered layer of channels x window samples, written column by column at the write position, which wraps to column 0 at the end of the window and starts a new sweep. Left of the write position is the current sweep, from it on the previous one. Freezing keeps a copy of both layers and of the write position for display while writing goes on.
