Detailed Description

Export macro of mne_mri — Volume I/O, voxel geometry and slice resampling for structural MRI data inside mne-cpp.

Hosts every public type that participates in loading a 3D MRI volume (MGH/MGZ, NIfTI-1, FreeSurfer COR), describing it in memory (mne::MriVolData, mne::MriSlice), resampling it onto an orthogonal viewing plane (mne::MriSlicer, mne::MriSliceImage) and re-serialising it through the FIFF MRI block hierarchy (mne::MriCorFifIO).

MRISHARED_EXPORT marks the public symbols: exported when building the shared library, imported by its clients, and empty in a static build (STATICBUILD).
