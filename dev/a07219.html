Detailed Description

The bundled fonts as a FontSource, with installed fonts for other families and missing characters.

A Font without family, or asking for "Source Sans 3", "sans-serif" or another generic sans family, is drawn in the bundled Source Sans 3, bold in its Semibold; "monospace" and "Source Code Pro" in the bundled Source Code Pro. Another family is taken from the system fonts when it is installed, else the bundled family that fits its name. A character the face lacks is taken from the other bundled faces, then from any installed face that has it, else the missing-glyph box is drawn.

// Text in the bundled Source Sans 3, laid out with the metrics of what is drawn; without RasterOptions::fonts
// the bitmap font draws, as above
const std::shared_ptr<const FontLibrary> fonts = FontLibrary::shared();
const FontTextMetrics fontMetrics(fonts);
const DisplayList typeset = plot.render(480, 320, fontMetrics, Font{"", 0.0, 13.0});
RasterOptions fontOptions;
fontOptions.fonts = fonts.get();
const Expected<void> typesetPng = to_raster(typeset, fontOptions).save_png(dir / "plot_fonts.png");
