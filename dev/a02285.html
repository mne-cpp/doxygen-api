mne::MNERawData mirrors mneRawDataRec: it pairs an mne::FiffInfo with the list of mne::MNERawBufDef entries that describe the on-disk layout of FIFF_DATA_BUFFER blocks of a -raw.fif file. It is the data source used by the C-ported routines in mne_browse_raw / mne_make_movie. New code should prefer mne::FiffRawData; this class exists for round-trip parity.
