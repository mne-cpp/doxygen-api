Detailed Description

Native sample formats and memory layouts stored in an acquisition ring.

Rings hold the device's own sample format in host byte order; backends that receive another byte order swap while writing. Physical values are produced only on request by the converters in acq_convert.h. Packed int24 is little-endian, three bytes per sample, as delivered by most 24-bit biosignal ADCs.
