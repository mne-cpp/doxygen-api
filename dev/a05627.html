Detailed Description

Settings for the mne_dipole_fit driver (forward model, guess grid, data, projections, output).

Command-line and programmatic settings for the mne_dipole_fit driver: BEM / sphere model, EEG model, guess-grid parameters, noise-covariance file, measurement file + time window, projection list, per-channel-type regularisation and output dip/bdip file names. Can be populated from argc / argv or directly by application code.
