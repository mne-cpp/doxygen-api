Detailed Description

Shows and edits a SettingsForm in a Surface, drawn toolkit-free in the look of a Theme.

The title of the form comes first, then each group as a card with one row per visible field: the label on the left, the editor on the right. Bool fields are switches, numbers steppers with - and + buttons (the wheel steps too), choices cycle with < and > buttons, text, path and directory fields are line edits, actions buttons, colours swatches and info fields toned text. The item lists of a panel fill their custom fields as list boxes: a click selects, Ctrl or Cmd extends the selection of multi-selection lists, the wheel scrolls them, the arrow keys move the selection and Delete removes the selected items of removable lists. The item trees of a panel are list boxes of their visible nodes, indented by depth, with a marker in front of nodes with children: a click on the marker or a double click expands or collapses the node, a click selects it, Up and Down move the selection, Right expands or goes to the first child, Left collapses or goes to the parent and Delete asks the tree to remove the node. Disabled fields are greyed and ignore input. The view follows the form: it lays out again when fields are added, removed or relabelled and repaints when values change. Content taller than the surface scrolls with the wheel.

The form must outlive the view.

std::unique_ptr<Panel> panel;
if (which == "compensator") {
auto compensator = std::make_unique<CompensatorPanel>();
std::vector<mne::FiffCtfComp> comps(3);
for (int i = 0; i < 3; ++i) {
comps[static_cast<std::size_t>(i)].kind = i + 1;
}
compensator->set_compensators(comps);
compensator->set_selection_callback([](int to) {
std::printf("Compensation grade %d\n", to);
});
panel = std::move(compensator);
} else {
auto projectors = std::make_unique<ProjectorsPanel>();
std::vector<mne::FiffProj> projs(4);
const char* descriptions[] = {"Average EEG reference", "PCA-v1 (planar)", "PCA-v2 (axial)", "ECG-planar-999--0.200-0.400-PCA-01"};
for (std::size_t i = 0; i < projs.size(); ++i) {
projs[i].desc = descriptions[i];
projs[i].active = i != 2;
}
projectors->set_projectors(projs);
projectors->set_selection_callback([](const std::vector<mne::FiffProj>& selected) {
std::printf("Projectors:");
for (const mne::FiffProj& proj : selected) {
std::printf(" %d", proj.active ? 1 : 0);
}
std::printf("\n");
});
panel = std::move(projectors);
}
FormView view(*panel);
view.set_text_metrics(&metrics);
return host.run(view);
