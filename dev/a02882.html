Panel: a toolkit-free tool panel of the applications, shown by any backend.

A panel (compensators, projectors, forward model settings, ...) holds the state and rules of one tool and describes its user interface with the generic building blocks of mne_viz, such as a SettingsForm. Each backend implements one generic host for panels instead of a hand-written view per tool, so the tools look the same everywhere and a new backend shows all of them.
