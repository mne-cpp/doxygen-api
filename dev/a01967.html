Bar renders a MATLAB-style bar() chart in pure QPainter into a QWidget canvas. The data interface is templated on the value type and accepts class limits and per-bin counts as Eigen column or row vectors, together with a precision hint controlling how many significant digits of the limit values are printed below each bin. It is used by histogram-oriented dialogs (e.g. evoked amplitude or noise distributions) where a lightweight, dependency-free histogram is sufficient.
