Detailed Description

The single producer of a ring: the backend for an input stream, the application for an output stream. Move-only. All members except create() and updateInfo() are allocation-free and lock-free; on input streams without a gating reader they are also wait-free.

Producing an input block, scheduling an output pulse at an exact sample, and driving a card that writes into the ring by DMA:

auto view = input.beginWrite(kBlock);
std::uint64_t s = view->firstSample();
for (std::size_t p = 0; p < view->partCount(); ++p) {
const AcqWritePart& part = view->part(p);
for (std::size_t i = 0; i < part.samples; ++i, ++s) {
auto* frame = reinterpret_cast<std::int16_t*>(part.at(0, i));
for (std::size_t c = 0; c < kChannels; ++c) {
frame[c] = gen.value(s, c);
}

AcqEvent marker;
marker.sample = s;
marker.duration = kSpikeWidth;
marker.code = 1;

}
}

◆ grant()

AcqError AcqWriter::grant ( std::size_t samples)
noexcept

Input streams written by a device (DMA): allows the device to write the next samples samples after those already granted, directly into the ring. From now on the device may overwrite anything older than the granted end minus the capacity, so readers count those samples as lost; commit() publishes granted samples as the device reports them written. Keep several blocks granted so the device never stalls; do not also beginWrite() the granted samples.

Parameters
[in]samplesSamples per channel.
Returns
InvalidParameter if more than the capacity would be granted beyond writePosition(), Timeout if a gating reader has not yet consumed the space, WrongDirection for output streams (there the device is the gating reader).
