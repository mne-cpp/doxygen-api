Detailed Description

Receives the tokens of a JSON stream from JsonStreamParser, in document order, without a DOM.

Override the callbacks of interest; the others do nothing. Strings and keys are views that are valid only during the call: they point into the chunk passed to JsonStreamParser::feed() when the token was complete and unescaped in it, and into a reused buffer otherwise, so no callback allocates. Callbacks must not call feed(), finish() or reset() of the parser that calls them.

JsonStreamParser stream; // NDJSON from a socket, split anywhere
std::vector<double> latencies;
stream.set_document_callback([&](JsonDocument&& event) { latencies.push_back(event["latency"].to_double()); });
for (const std::string_view packet : {"{\"latency\":1.5}\n{\"lat", "ency\":2", ".25}\n{\"latency\":3}"}) {
if (!stream.feed(packet)) { // malformed input: report and resynchronize
Log::warning("bad JSON at byte {}: {}", stream.error().offset, stream.error().error_string());
stream.reset();
}
}
