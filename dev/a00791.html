Detailed Description

Command-line and programmatic settings struct for the mne_dipole_fit driver.

mne::InvDipoleFitSettings collects every option that the classic mne_dipole_fit command-line tool accepts — BEM file, sphere origin, EEG model, guess-grid parameters, noise-covariance file, measurement file and time window, projection list, regularisation per channel type, and output dip/bdip file names. The class can be populated from argc / argv (for the mne_dipole_fit binary) or directly by application code, and checkIntegrity validates the combination of choices before the fit workspace is built. Refactored from setup.c / argument-parsing code in MNE-C.
