Detailed Description

Top-level convenience entry points that mirror MNE-Python's apply_inverse_* / compute_source_psd helpers.

Free functions in this header glue together the lower-level mne_inv classes so users can match the MNE-Python ergonomics: mne::apply_inverse_epochs applies a precomputed inverse operator across an epoch list, apply_inverse_raw streams raw data through the kernel, estimate_snr returns the whitened-data SNR trace from an evoked + inverse pair, compute_whitener produces the diagonal whitener from a noise covariance, and compute_source_psd / compute_source_band_power run Welch-based spectral analysis directly on mne::InvSourceEstimate output. All methods are headers-only orchestration on top of mne::InvMinimumNorm and the underlying FIFF / MNE primitives.

// Whitened data and a gain per nAm make the noise level 1, as mne.inverse_sparse.mixed_norm does.
const auto [whitener, rank] = compute_whitener(inverse.noise_cov); // rank 360: 364 channels minus 4 projectors
const MNEForwardSolution fixedFwd = MNEForwardSolution(fwdPath, {.force_fixed = true, .surf_ori = true}).pick_regions({v1}).pick_channels(inverse.noise_cov.names);
const MatrixXd gain = whitener * fixedFwd.sol.data * 1e-9;
const MatrixXd measured = whitener * evoked.pick_channels(inverse.noise_cov.names).data.middleCols(170, 40); // 83-148 ms
const double alphaMax = (gain.transpose() * measured).rowwise().norm().maxCoeff();
const InvMxneResult mxne = InvMxne::compute(gain, measured, 0.5 * alphaMax, 1000, 1e-10);
