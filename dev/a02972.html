Detailed Description

Generic tab-separated-value reader/writer for BIDS sidecars (UTF-8, LF, n/a for missing values, mandatory header row).

BIDS standardises a strict TSV dialect for every tabular sidecar: a mandatory header row defines the column names, values are separated by single literal tabs, missing values are encoded as the three-byte string n/a, and the file MUST be UTF-8 encoded with LF (no CR) line terminators. mne::BidsTsv implements that dialect once via BidsTsv::read_tsv / BidsTsv::write_tsv so the domain-specific wrappers mne::BidsChannel, mne::BidsElectrode and mne::BidsEvent do not each re-derive it. Rows are returned as ordered column-name → value maps (BidsTsvRow), preserving the header ordering for round-trip-stable writes.
