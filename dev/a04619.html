Detailed Description

An RGB image in memory that fills polygons, draws text and writes PNG files.

Polygons are filled with the non-zero winding rule and anti-aliased by 4 x 4 supersampling, so their edges blend with what is underneath like QPainter's anti-aliased drawing.

// Qt: QImage image(64, 48, QImage::Format_RGB32); QPainter p(&image); p.drawPolygon(...); image.save("frame.png");
RasterImage frame(64, 48, {0, 0, 0});
const std::array<PointF, 3> triangle = {{{4.0, 40.0}, {60.0, 40.0}, {32.0, 4.0}}};
frame.fill_polygon(triangle, {255, 128, 0}); // anti-aliased edges
frame.draw_text(2, 47, "t = 12.5 ms", {255, 255, 255});
const std::vector<std::uint8_t> png = frame.encode_png(); // or frame.save_png(path)

Draws text with the built-in 5 x 7 pixel font, one pixel of spacing between characters.

The font covers digits, letters (upper-case letters are drawn as lower-case ones) and the characters space . , : ; + - = / % ( ) _ ; other characters are drawn as a box.

Parameters
[in]xLeft edge of the first character.
[in]baselineRow below the last row of the characters.
[in]textASCII text.
[in]colorText colour.
[in]scaleSize of a font pixel in image pixels, at least 1.
