Detailed Description

SdlHost shows any mne_viz view in an SDL3 window.

SdlHost opens an SDL3 window, translates SDL mouse, wheel and key events to the input events of mne_viz and hands them to a SurfaceClient. Each frame the client describes is executed by the software renderer of mne_viz and shown as an SDL texture, so neither Qt nor a GPU is needed; SDL's dummy video driver runs it headless.
