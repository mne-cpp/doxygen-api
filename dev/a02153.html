The implementation walks the MnaSession list with the matching session codec and emits freesurfer_dir as a relative POSIX path so projects remain portable between hosts. Any subject-level fields not recognised by this build — demographics, consent flags, clinical metadata — are routed through extras to guarantee round-trip fidelity with newer mne_mna versions.
