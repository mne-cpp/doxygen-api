Mirrors a curated subset of the mne_types.h shipped with the original MNE C tooling so ported code can continue to refer to the familiar constants (source-space types, channel-selection origins, CTF compensation grades, the default trigger channel) without dragging the full C header tree into every consumer. It holds constants only and includes no other mne_mne header.
