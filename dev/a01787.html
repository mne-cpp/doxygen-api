Detailed Description

Host-agnostic controller that owns the ordered scene-layer stack (MRI slice, BEM, cortex, sensors, dipoles, networks, overlays).

MultimodalScene composes the disp3D primitives into a single depth-sorted layer stack so the GUI shell does not need to know the per-modality render order. Each mne::disp::SceneLayer carries its renderable, a sort key and a visibility flag; the controller iterates layers in order and issues the corresponding draw calls.

It also routes pick events from mne::disp::RayPicker through every layer and returns a uniform mne::disp::PickResult to the host, hiding the per-primitive intersection logic.
