Detailed Description

A consumer of one AcqStream. Move-only; destroying it frees its reader slot.

auto view = reader.acquire(kBlock, 100ms);
if (!view) {
if (view.error() == AcqErrorCode::EndOfStream) {
break;
}
continue;
}

◆ ReadMode

enum class mne::AcqReader::ReadMode : std::uint8_t
strong

Consumption mode.

Enumerator
Lossless 

Every sample in order; an overrun is reported with its exact count and the reader resumes at the oldest retained sample.

Latest 

The newest samples; older ones are skipped (counted, not lost). For displays.

LowLatency 

Like Lossless, woken by busy-poll for the shortest commit-to-wake latency.

AcqExpected< AcqBlockView > AcqReader::acquire ( std::size_t minSamples,
std::chrono::nanoseconds timeout,
std::size_t maxSamples = 0 )
nodiscardnoexcept

Waits until at least minSamples are available (Latest: the newest minSamples), then returns a view of up to maxSamples. Larger blocks amortise the per-view cost; pass maxSamples = 0 to take everything available. One view per reader at a time.

Parameters
[in]minSamplesSamples per channel required; 0 returns immediately (device polling).
[in]timeoutMaximum wait.
[in]maxSamplesUpper bound of the view, 0 for everything available.
Returns
The view, or Timeout, EndOfStream, DeviceStopped, InvalidState (a view is already held).
