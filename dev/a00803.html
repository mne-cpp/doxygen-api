mne::InvSensorSet replaces the verbose mne::FwdCoilSet for read-only use by the HPI fit loop: it stores per-channel integration-point positions rmag, surface normals cosmag, channel transforms tra and integration weights w in dense Eigen matrices, plus the linear-combination matrix that maps coil integration points back to channels. The mne::InvSensorSetCreator helper builds an mne::InvSensorSet from an mne::FwdCoilSet, picking the requested integration accuracy (high / medium / low) so the HPI cost function can run on a small hot-loop-friendly data structure.
