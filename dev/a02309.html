Detailed Description

SettingsStore persists view state as key/value pairs in whatever storage a backend provides.

Views remember their state (camera, visibility, shaders) between runs. They read and write it through SettingsStore, so the storage is the backend's choice: QSettings in the Qt backend, a file or memory elsewhere. MemorySettingsStore keeps the values in memory, for tests and hosts without persistent settings.
