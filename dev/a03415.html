◆ decimate_trace()

std::vector< float > mne::scene::decimate_trace ( std::span< const float > samples,
int pixel_width,
Detrend detrend = Detrend::None )

Turns a window of samples into trace vertices (interleaved x, y with x the offset from the first sample).

Up to two samples per pixel every sample is a vertex. Beyond that the window is split into pixel_width bins, each drawn as its maximum and then its minimum at the bin start, so that a line strip draws the min/max envelope (2 vertices per pixel).

Parameters
[in]samplesThe window.
[in]pixel_widthPixels the window spans; nothing is returned if it is not positive.
[in]detrendTrend to subtract; for bins it is taken at the bin centre.
Returns
The vertices.
Since
3.0.0

[in]markersEvents and epoch markers.
[in]styleColours and scales.
