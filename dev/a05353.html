Detailed Description

Digitizer points with the names of their EEG electrodes, like mne.channels.DigMontage.

The points come in the order of mne.channels.make_dig_montage: the cardinal points (LPA, nasion, RPA), HPI coils, head shape points, then the EEG electrodes. Electrodes are numbered by the last three characters of their names when all of those are numbers, and 1..n otherwise; a repeated name keeps its first place and its last position. All points are in digitizer coordinates (FIFFV_COORD_UNKNOWN) and in metres.

const auto montage = FiffDigMontage::read_neuroscan_dat(datPath); // mne::Expected, like mne.channels.read_dig_dat

staticnodiscard

Reads the coordinates.xml of an EGI MFF recording, as mne.channels.read_dig_egi does.

Sensors of type 0 become EEG electrodes named "EEG <number>", the reference (type 1) is numbered after the electrodes before it, and the nasion and periauricular points (type 2) become the cardinal points. Unlike mne.channels.read_dig_egi, which keeps the file's centimetres as if they were metres, the positions are converted to metres (as mne.io.read_raw_egi does).

Parameters
[in]pathThe coordinates.xml file.
Returns
The montage, or why the file cannot be read: Io if it cannot be opened, Format if it cannot be parsed, a sensor has no number or position or a fiducial is missing.
