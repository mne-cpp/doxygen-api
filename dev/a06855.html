Detailed Description

The channels picked in a sensor layout: names, numbers, kinds, units and layout positions, one entry per channel in each vector.

The hosts of mne::viz::ChannelSelectionPanel pass it on when the selection changes; the average layout and the analysis plugins show only these channels.

Header-only, so it is not exported: an exported class with only inline members leaves MSVC users referencing imports the DLL never defines.
