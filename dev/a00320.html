A ring can be the memory a PCIe card or a network adapter writes by DMA, including GPU memory written by GPUDirect RDMA. The library never dereferences sample memory the CPU may not touch; ring positions, events and segment headers always live in host memory, so the stream protocol is the same everywhere.
