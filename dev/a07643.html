Detailed Description

Tool panel of 3D views: the loaded data, view options (full screen, automated rotation, coordinate axis, single or multiple views, scene colour, screenshot) and light options (colour and intensity).

The loaded data is a Custom field (data_key) the host fills with its own tree view of the 3D model, since that model is hierarchical and edited in place. Which parts show is chosen with flags ("Data", "View", "Light"). The options are not persisted, as hosts do not apply them on start. Setters are silent; user edits call the callbacks.
