AcqUri and AcqDeviceRegistry: URI scheme -> backend factory, and discovery (control path).

URIs have the form scheme://target?key=value&key=value. Every scheme opens with no parameters where that is meaningful (synthetic://, lsl://NAME, fiff://FILE). Parameters are parsed into a typed configuration by each backend; unknown keys are an InvalidParameter error, never silently ignored. Built-in backends register at static-initialisation time; applications can add their own.
