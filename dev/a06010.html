Detailed Description

One item in a derivation data set.

Holds a sparse named matrix of derivation coefficients together with validity and usage metadata and matched channel information.

int MNEDeriv::validate ( const std::vector< mne::FiffChInfo > & chInfo)

Checks every derived channel against channel info (MNE-C mne_validate_deriv).

A derived channel is valid if all its inputs are present and of the same kind and unit; valid and chs are filled, chs with the info of the first input.
