Detailed Description

Path-keyed parameter store with formula-driven dynamic bindings.

Hierarchical parameter store keyed by "nodeId/attrKey" paths, with bindings that recompute parameters from formulas.

Formulas combine numbers, true/false, 'text', names (a parameter, else a result), ref('path'), the functions clamp(v, lo, hi), scale(v, f), threshold(v, t, above, below) and lerp(a, b, t), the operators + - * / with parentheses, and one comparison (>= <= == != > <). Names may contain '.', ':' and '/', so put spaces around a division that follows a name.

graph.param_tree.set_param("shift/offset", 0.5);
MnaParamBinding binding;
binding.target_path = "scale/gain";
binding.expression = "clamp(ref('source::out') * 2, 0, 5)"; // evaluated against node results
binding.trigger = "on_change";
graph.param_tree.add_binding(binding);
