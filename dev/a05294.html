Detailed Description

One CTF software-gradient compensation matrix: grade kind, calibration flag and the gradiometer × reference named matrix.

A list of FiffCtfComp lives inside FiffInfo and lets raw / evoked data be moved between compensation grades by chaining the appropriate matrices. The save_calibrated flag controls whether the matrix was stored already-calibrated (and therefore must not be re-multiplied by the channel cals on apply).

◆ calibrate()

bool FiffCtfComp::calibrate ( const std::vector< FiffChInfo > & chs)

Brings a compensator stored uncalibrated into calibrated units, as mne _read_ctf_comp does: each matrix element is scaled by its row channel's range * cal and divided by its column channel's. The factors are kept in rowcals and colcals so that write_ctf_comp can undo them. A compensator saved calibrated is left as it is.

Parameters
[in]chsThe channels the compensator refers to by name.
Returns
false if a row or column channel is missing from, or ambiguous in, chs.
