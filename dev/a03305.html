◆ surfaceColors()

QVector< uint32_t > ElectrodeObject::surfaceColors ( const Eigen::MatrixX3f & vertices,
double distance = 0.01 ) const

Paint the contact values onto a surface, as MNE-Python's stc_near_sensors: each vertex takes the distance-weighted mean of the contacts within reach and fades out with the summed weight. ECoG contacts are first moved onto the surface; depth contacts are not.

Parameters
[in]verticesSurface vertex positions in the frame of the implantation, metres.
[in]distanceReach of each contact in metres.
Returns
ABGR colour per vertex, transparent away from the contacts; empty without values.
