Detailed Description

Powell-accelerated RAP-MUSIC variant — replaces the exhaustive pair scan with a Powell line-search refinement.

mne::InvPwlRapMusic derives from mne::InvRapMusic and overrides the pair-scanning step with a Powell direction-set optimiser, drastically reducing the number of leadfield evaluations per iteration on dense grids. All other behaviour — signal-subspace estimation, recursive projection, stopping criterion, output assembly — is inherited from the base class so results stay comparable to the exhaustive scanner.
