Detailed Description

MultimodalScene — host-app-agnostic controller that owns ordered renderables (cortical surface, sEEG/ECoG electrodes, MRI ortho slices, sensors, dipoles, network graph) and drives a single QRhi pass with consistent depth-test and alpha blending.

Required by the mne_analyze cortical workflow and the MNE Inspect multimodal visualisation, and reusable from the mne_align coregistration helper app's lightweight 3-D view.

v2.3.0 ships the public data model, layer registry, picking dispatch, and shared timeline. The QRhi rendering glue is implemented incrementally per consumer (see view/brainrenderer.h for the existing single-renderable pipeline).
