std::optional< MNEEventList > MNEEventList::read_text ( const std::filesystem::path & path,
int offset,
int old_offset,
float sfreq )
static

Reads an MNE-C text event file (MNE-C mne_load_events).

Each line holds sample, time, trigger value before and after, and an optional comment; # starts a comment line. A negative sample is computed from the time. A first line with both trigger values 0 marks the current format: it gives the first sample of the recording and is not an event. Old files have no such line; their samples are shifted by old_offset instead.

Parameters
[in]pathThe text file.
[in]offsetSamples to subtract from every event (the recording's first sample).
[in]old_offsetExtra offset used by files in the old format.
[in]sfreqSampling frequency, to convert times of events without a sample.
Returns
The events, or no value if the file cannot be read or holds no events.
