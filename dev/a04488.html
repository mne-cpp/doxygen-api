Detailed Description

MATLAB-style line plot for an Eigen vector, derived from Graph.

Owns a list of std::vector<QPointF> trace paths and supports a m_bHoldOn flag for overlaying multiple curves. updateData() replaces the visible curve in place.

VectorXd samples = VectorXd::LinSpaced(50, -1.0, 1.0);
Plot plot(samples); // Plot is a Graph with title and axis labels
plot.setTitle("ramp");
plot.setXLabel("sample");
plot.setYLabel("value");
