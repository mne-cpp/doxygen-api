Detailed Description

Set of averaged evoked responses sharing a FiffInfo, plus the ave-style category / rejection descriptors for batch averaging.

A single *-ave.fif typically contains several FIFFB_EVOKED blocks (one per stimulus condition / averaging category). mne::FiffEvokedSet groups them: a shared mne::FiffInfo and a list of mne::FiffEvoked instances, plus channel-picking and compensation helpers that apply uniformly to the whole set.

The header additionally ports the three batch-averaging descriptor structs from MNE-C's browser_types.h (mne::RejectionParams, mne::AverageCategory, mne::AverageDescription) so the mne_browse_raw "ave description" files can be parsed and consumed verbatim. Together they describe artifact-rejection thresholds, per-category timing and trigger logic, and the file-level output settings used by the mne_process_raw averaging pipeline.
