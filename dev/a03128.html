FIFF events are the standard integer representation of trigger / stim information: each event is a (sample, previous_value, new_value) triple, and a list of them is stored under FIFFB_MNE_EVENTS. The mne::FiffEvents class owns one such list and exposes the operations the rest of mne_fiff needs: read / write FIFF event files, detect events on a stim channel of a mne::FiffRawData (parity with mne.find_events), filter by code, and clip to a sample range.
