Lightweight pairwise source-connectivity container that travels alongside a source estimate.

INVLIB::InvConnectivity stores one N×N connectivity matrix between source-space grid points together with its measure name (coherence, imCoh, PLV, PLI, wPLI, Granger, PDC, DTF, ...), direction flag and frequency/time window. The struct is deliberately decoupled from the connectivity library so an INVLIB::InvSourceEstimate can carry multiple connectivity layers (one per band / window) without pulling in the full CONNECTIVITY graph machinery.
