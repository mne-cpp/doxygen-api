One input stream "raw" of Float32 values scaled by cal / gain, with the channels, sensor positions and coil types the server describes; its gains are read again at every open. The trigger lines TRG001 to TRG008 above the threshold make up a digital trigger word, which goes into DTRG01 and whose changes are events.
