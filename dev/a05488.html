Detailed Description

FIFF tag-stream reader/writer: exposes typed read_* / write_* methods for every FIFF block and record kind.

Reads or writes one byte stream. Builds the FIFF directory and FiffDirNode block tree on open and exposes typed loaders / emitters for every structured record (id, channel info, coord trans, named matrix, dig point, projector, CTF comp, raw segment, evoked, covariance). The on-disk format is the Elekta/Neuromag FIFF specification — files emitted here round-trip through mne.io.fiff in MNE-Python without modification.

FiffStream stream(QString(dir + "/sample_audvis-ave.fif").toStdU16String());
const bool opened = stream.open();
const std::vector<std::shared_ptr<FiffDirNode>> measNodes = stream.dirtree()->dir_tree_find(FIFFB_MEAS_INFO);
const std::optional<FiffTag> nchan = measNodes.front()->find_tag(stream, FIFF_NCHAN); // raw tag access
const FiffId fileId = stream.id();
stream.close();
