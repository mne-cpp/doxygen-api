mne::InvSignalModel builds the model matrix that pairs the HPI coil drive frequencies (and, optionally, the line-frequency harmonics) with the sample window length defined by the input data. Inverting the model with a pseudo-inverse projects the MEG buffer onto the per-coil amplitudes that mne::InvHpiFit feeds into the dipole search. The model matrix is cached and re-derived only when the mne::InvHpiModelParameters change or the number of samples in the buffer changes.
