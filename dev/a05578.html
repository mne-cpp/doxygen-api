Detailed Description

Source-space inverse-solution container with dense grid plus optional focal-dipole, coupling and connectivity layers.

Central source-space container produced by every mne_inv inverse solver. Carries the dense (n_sources × n_times) data matrix plus vertex indices, time origin and step, and optional focal dipoles, coupling groups and connectivity layers so one value can represent the output of any algorithm in mne_inv. Replaces mneStcDataRec of MNE-C and implements round-trip STC / W binary I/O with mne-python and mne-c.

FsLabel v1;
FsLabel::read((data + "/subjects/sample/label/lh.V1.label").toStdU16String(), v1);
const std::filesystem::path fwdPath = (data + "/Result/ref-sample_audvis-meg-eeg-oct-6-fwd.fif").toStdU16String();
const MNEForwardSolution fwd = MNEForwardSolution(fwdPath).pick_regions({v1}); // 70 sources x 3 orientations
const FiffCov noiseCov((data + "/MEG/sample/sample_audvis-cov.fif").toStdString());
const FiffEvoked evoked((data + "/MEG/sample/sample_audvis-ave.fif").toStdU16String(), 0); // "Left Auditory"
const MNEInverseOperator inverse = MNEInverseOperator::make_inverse_operator(evoked.info, fwd, noiseCov, 0.2f, 0.8f);
const float lambda2 = 1.0f / 9.0f; // SNR 3
InvMinimumNorm dspm(inverse, lambda2, "dSPM");
const InvSourceEstimate stc = dspm.calculateInverse(evoked); // one row per source, combined over orientations
const std::filesystem::path csvPath = tmp.filePath("v1-dspm.csv").toStdU16String();
const bool csvWritten = InvSourceEstimateIO::write_csv(stc, csvPath);
const InvSourceEstimate fromCsv = InvSourceEstimateIO::read_csv(csvPath);
const std::filesystem::path stcPath = tmp.filePath("v1-dspm-lh.stc").toStdU16String();
const bool stcWritten = stc.write(stcPath).has_value(); // MNE .stc format, readable by mne.read_source_estimate
const InvSourceEstimate fromStc(stcPath);
