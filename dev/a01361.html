Detailed Description

GpuFrame describes what a view draws on a GPU (buffers, pipelines, passes, draws) without a graphics API.

A view keeps its buffers, textures and pipelines in a GpuResources store across frames and builds one GpuFrame per frame that lists the passes and draws referring to them. A backend executes the frame: the QRhi backend of mne_disp uploads changed resources and records the draws, SoftwareRenderer rasterizes them into an image. Shaders are named by an id; every backend implements the id (precompiled .qsb for QRhi, C++ for software).
