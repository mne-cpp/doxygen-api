SourceEstimateSession couples mne::viz::SourceEstimateOverlay (the static colour-mapped renderable), mne::viz::StcLoadingWorker (background loader for .stc files) and mne::viz::RtSourceStream (the real-time pipeline) into a single object that the GUI talks to. It exposes time-point scrubbing, playback, looping and threshold / colormap selection without leaking the worker-thread plumbing.
