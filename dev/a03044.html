mne::FilterThreadArg bundles the input buffer, an mne::MNEFilterDef and the completion callback that the legacy raw-browser filter worker thread needs to run a filter on one FIFF data buffer asynchronously. Kept POD-like so it can be passed across thread boundaries without ownership headaches.
