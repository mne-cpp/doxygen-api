Declarative contract for an MNA operation — expected input/output ports, attributes, binding kind and validation against a concrete mne::MnaNode.

mne::MnaOpSchema is the type information an MNA operation publishes to the rest of the system. It declares the op_type identifier, version, category and binding mode (internal in-process function, cli external executable driven by cli_template, or script delegating to an inline mne::MnaScript), plus the mne::MnaOpSchemaPort and mne::MnaOpSchemaAttr lists that describe expected I/O and parameters with their data kinds, default values and required flags.

The MnaOpSchema::validate method is the gatekeeper used by MnaGraph::validate and the GUI editor: it checks that a concrete mne::MnaNode declares every required port, that the attribute types match QMetaType expectations, and that no unknown attribute leaks through. Schemas are normally authored declaratively in mna-registry.json and loaded by mne::MnaRegistryLoader rather than written in C++.
