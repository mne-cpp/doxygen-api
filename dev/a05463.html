Detailed Description

One-call FIFF reader/writer: opens a file, dispatches to the right specialized loader and returns ready-to-use mne_fiff containers.

Sniffs the FIFF block tree, dispatches FiffRawData / FiffEvokedSet loaders as appropriate, and returns shared pointers so the resulting objects can be freely passed across the rest of the pipeline. Front-end parity with mne.io.read_raw_fif and mne.read_evokeds.

FiffIO io(QString(dir + "/sample_audvis-ave.fif").toStdU16String()); // detects what the file holds (raw, evoked, fwd, ...)
