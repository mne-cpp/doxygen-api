mne::InvHpiFit fits a magnetic dipole to each HPI coil from the projected MEG data, matches the fitted coils to the digitised coil locations and returns the resulting dewar↔head coordinate transform. The class drives the same pipeline used by Elekta/MEGIN MaxFilter and mne-python's mne.chpi: per-coil dipole localisation, frequency ordering, large-movement detection and quaternion-formatted position storage. Inputs are the projected sensor data, the SSP projector and an mne::InvHpiModelParameters spec; output is an mne::HpiFitResult that downstream stages can feed to head-movement-corrected averaging or continuous co-registration.
