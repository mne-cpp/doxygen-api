SettingsPanel builds Qt Widgets for any viz::SettingsForm.

The one Qt builder of the toolkit-neutral settings description: check boxes, spin boxes, sliders, combo boxes, line edits, file and directory choosers, colour buttons, read-only texts and buttons in group boxes, kept in step with the form both ways, with the enabled and visible conditions of the fields applied. Values persist in QSettings.
