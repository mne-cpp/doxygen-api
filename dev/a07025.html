Detailed Description

Magnitude response of a filter from 0 Hz to the Nyquist frequency, in dB relative to its maximum.

The response is normalised to its largest value, so the pass band sits at 0 dB, and cut at the floor (-100 dB by default). Cut-off frequencies are vertical marker lines. When the response has more points than the plot has pixels, each pixel column draws the lowest and highest value it covers, so narrow notches stay visible.

// Magnitude of a 5-pole Butterworth low pass at 30 Hz, sampled at 250 Hz
std::vector<double> magnitude(501);
for (std::size_t i = 0; i < magnitude.size(); ++i) {
magnitude[i] = 1.0 / std::sqrt(1.0 + std::pow(static_cast<double>(i) * 0.25 / 30.0, 10));
}
FilterResponsePlot response;
response.set_title("Low pass 30 Hz");
response.set_response(magnitude, 125.0);
response.set_cutoffs({30.0});
const DisplayList responseFigure = response.render(480, 320, metrics, Font{"", 0.0, 13.0});
