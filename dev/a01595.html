One input stream "eeg" in the API's format: a float per channel in microvolts, so with 1e-6 as scale. The inputs of the master come first, then those of each slave, as EEG 001..EEG nnn; the master's trigger line, if enabled, is STI 014. A change of the trigger line away from its value at the start is pushed as an event at that sample, with the value as code.
