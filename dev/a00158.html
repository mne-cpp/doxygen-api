The MNE-Matlab toolbox exposes file I/O as flat functions (fiff_open, fiff_read_raw_segment, fiff_read_evoked, ...). FIFF mirrors that surface as a static-method facade so code ported from Matlab compiles unchanged. New C++ code should call the underlying class methods directly (FIFFLIB::FiffStream, FIFFLIB::FiffRawData, FIFFLIB::FiffEvoked, ...) — the wrapper only exists for the backwards-compatible path.

Including fiff.h is also the single-include shortcut that pulls in every public FIFFLIB header in one go, which is convenient for prototyping and for tools that need the full type universe.
