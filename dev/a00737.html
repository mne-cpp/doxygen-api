Detailed Description

QWindow host of the 3-D brain view that owns its QRhi and swap chain and needs no Qt Widgets.

BrainWindow shows a mne::disp::BrainViewCore in a plain QWindow: it creates a QRhi for the platform (Metal on macOS, Direct3D 11 on Windows, OpenGL elsewhere, or the Null backend for tests), a swap chain with a depth-stencil buffer, renders on expose and on update requests, resizes the swap chain with the window and forwards mouse, wheel and key events to the core.

Widget applications embed it in their widget tree through a window container created with createWindowContainer() of the widget module; the container takes ownership of the window. disp3D itself does not depend on that module for this class.
