Detailed Description

Subjects, sessions, data-type folders and data items of a BIDS browser.

Nodes are addressed by ids that stay valid until the node is removed. The item types use the values of the BIDS_* constants of viz::qt::BidsViewModel (subject 1, session 2, folder 3, functional 10, anatomical 11, behavioral 12, iEEG 13, average 20, event 21, dipole 22, electrodes 23, coordinate system 24, unknown 99).
