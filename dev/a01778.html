fiff://FILE opens a raw FIFF file as a device with one input stream. Samples keep the file's native format (FIFFT_DAU_PACK16 and FIFFT_SHORT as int16, FIFFT_INT as int32, FIFFT_FLOAT as float32, FIFFT_DOUBLE as float64), and each channel's scale is range * cal, so scale * sample equals FiffRawData::read_raw_segment bit for bit; skipped buffers read as zeros. Stream sample 0 is the file sample selected with start.

Events come from the trigger channel (stim, or STI101, STI 101, STI 014, then the first stim channel): one at every sample where the value changes to a non-zero value, lasting while the value is held, as mne.find_events(raw, consecutive=True). A value held from the first file sample is not an event.

Parameters: loop (restart at the first file sample at the end; default 0, the stream ends), realtime and speed (pacing), start (seconds into the file), block (samples per commit), events, stim, cpus, priority.
