Detailed Description

Widgets-free QRhi renderer and input handler of the raw-data channel trace view.

ChannelRhiRenderer is the Qt side of the raw-trace view: it converts input events and records the frames of mne::viz::TraceFrameBuilder into any QRhi render target with mne::viz::qt::RhiFrameRenderer. The logic is Qt-free in mne_scene: mne::viz::TraceView (viewport, interaction state, HUD overlays), mne::viz::TraceFrameBuilder (trace vertices, textures and draws of a frame), mne::viz::TraceMarkers (annotation, event and epoch overlay) and mne::viz::ViewAnimator (scroll and zoom animations). It only depends on QtCore and QtGui: a host (the QRhiWidget mne::viz::qt::ChannelRhiView or the QWindow mne::viz::qt::ChannelWindow) implements mne::viz::qt::ChannelRhiHost, forwards its input events and calls renderFrame().
