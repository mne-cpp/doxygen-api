ArtifactSettingsView wires a QCheckBox + QDoubleSpinBox pair for each enabled channel modality so the user can activate / deactivate amplitude rejection and dial in a peak-to-peak limit per channel type. Threshold edits emit changeArtifactThreshold(QMap) which the averaging / pre-processing pipeline consumes to discard epochs that exceed the limit on any participating channel.
