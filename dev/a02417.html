MNELIB::MNE is a thin collection of static utilities that mirror the function surface of the Python/Matlab MNE toolbox so existing tutorials and scripts translate one-to-one. It exposes wrappers around I/O for source spaces (MNELIB::MNESourceSpace), BEM models (MNELIB::MNEBem), hemispheres (MNELIB::MNEHemisphere) and epoch lists (MNELIB::MNEEpochDataList), plus algorithmic helpers for projection application, label-based clustering of forward solutions and SSP/CTF manipulation. The class never holds state; it only forwards to the underlying domain objects.
