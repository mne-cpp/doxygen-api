mne::InvEcdSet collects one mne::InvEcd per fitted time bin and exposes append, index access and stream-insertion as well as read/write support for the canonical .dip text format (mrilab) and the .bdip binary format (xfit). It is the value type returned by InvDipoleFit::calculateFit and serialised by the mne_dipole_fit driver.
