Detailed Description

Implementation of the MnaOpRegistry singleton, including the upward search for resources/mna/ and the drop-in registry merge logic.

The registry stores schemas and op functions in two QMap members keyed by op type. register_op and register_op_func both replace any existing entry so plug-ins loaded later can shadow built-ins by design. load_registry_files walks upward from QCoreApplication::applicationDirPath looking for a resources/mna/ directory, then delegates to MnaRegistryLoader::load_directory, which in turn reads the master mna-registry.json plus every drop-in under mna-registry.d/ in alphabetical order. missing_ops walks a supplied tool list and returns those entries with no registered schema, which is the simplest way to detect a stale or partial install before a graph is executed.
