mne::FiffStream is the workhorse of mne_fiff. It owns a byte stream (a file, or bytes in memory), reads and writes the 16-byte FIFF tag header, decodes payloads through the endian-swap helpers in fiff_byte_swap.h, and assembles the directory and block tree on the way in. The high-level methods then trade tag streams for typed objects: read_meas_info returns a mne::FiffInfo, read_raw_data returns a mne::FiffRawData, FiffEvoked::read returns a mne::FiffEvoked, read_cov returns a mne::FiffCov, etc. On the writing side start_writing_raw, write_tag, write_int / write_float / write_float_matrix, start_block / end_block and the record-level writers (write_id, write_ch_info, write_coord_trans, ...) emit a fully spec-compliant FIFF file that round-trips through MNE-Python and MNE-C unchanged.
