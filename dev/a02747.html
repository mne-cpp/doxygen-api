Detailed Description

Strongly-typed enumerations that tag a source estimate with the inverse method, source-space type, and orientation constraint that produced it.

Defines mne::InvEstimateMethod (MNE, dSPM, sLORETA, eLORETA, LCMV, DICS, SAM, MixedNorm, GammaMAP, DipoleFit, RapMusic, PwlRapMusic), mne::InvSourceSpaceType (surface, volume, mixed, discrete) and mne::InvOrientationType (fixed, free, loose). These tags travel on every mne::InvSourceEstimate so downstream consumers (visualisation, ROI extraction, tokenisation, CSV export) can branch on the algorithm and geometry that produced the data without re-inspecting matrix shapes.
