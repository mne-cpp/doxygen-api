Detailed Description

SSP parameters of compute_proj_ecg / compute_proj_eog; ecg() and eog() give the MNE-Python defaults.

ArtifactDetect::EcgParams ecg; // mne find_ecg_events defaults: 5-35 Hz, automatic QRS threshold
ArtifactDetect::EogParams eog; // mne find_eog_events defaults: 1-10 Hz, automatic peak threshold
const std::vector<int> beats = ArtifactDetect::detectEcg(data, info, kSFreq, ecg); // R-peak samples on the ECG channel
const std::vector<int> blinks = ArtifactDetect::detectEog(data, info, kSFreq, eog); // blink peaks on the EOG channel
