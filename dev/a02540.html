mne::MNECovMatrix mirrors the mneCovMatrixRec struct of the original MNE C tooling: a dense or diagonal noise covariance kept as a vector plus eigen-decomposition, used internally by routines ported verbatim from mne_inverse_operator. New code should prefer mne::FiffCov; this class exists so legacy algorithms can be translated without rewriting their algebra.
