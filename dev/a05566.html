Detailed Description

Single averaged evoked response: time axis, data, baseline, channel info and averaging metadata.

Holds one FIFFB_EVOKED block: times, data, first / last sample indices, baseline, kind, nave, comment and the FiffInfo describing the channels. Use FiffEvokedSet for recordings that contain multiple averaging conditions.

FiffEvokedSet evokedSet((dir + "/sample_audvis-ave.fif").toStdU16String()); // all conditions of an -ave.fif file
const FiffEvoked& leftAuditory = evokedSet.evoked[0];

FiffEvoked mne::FiffEvoked::combine ( const std::vector< FiffEvoked > & evokeds,
const Eigen::VectorXd & weights )
static

Merges evoked data by weighted addition or subtraction (mne.combine_evoked).

All data sets must have the same channels and time instants. The result carries the union of the bad channels, the weighted sum of the data, a comment such as "0.474 × A + 0.526 × B" and nave = 1 / sum(w_i^2 / nave_i), rounded to an integer as required by the FIFF format.

Parameters
[in]evokedsThe evoked data sets.
[in]weightsOne weight per data set.
Returns
The combined evoked data, or an empty FiffEvoked if the inputs are inconsistent.
