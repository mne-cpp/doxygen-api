Detailed Description

Widgets-free core of the 3-D brain view: scene wiring, camera, multi-view, picking, overlay and frame rendering.

BrainViewCore holds everything of the interactive 3-D brain scene that does not need Qt Widgets. It connects mne::viz::qt::BrainTreeModel data changes to scene rebuilds, translates QtGui mouse / wheel / key events for the toolkit-neutral mne::viz::BrainViewInteraction (orbit, pan, zoom, pane selection and splitters), takes the camera matrices from mne::viz::OrbitCamera, paints the 2-D overlay (FPS, per-pane info, pane names, hovered region, pane separators) of mne::viz::BrainViewOverlay, describes each frame with mne::viz::BrainFrameComposer and records it through mne::viz::qt::RhiFrameRenderer into a QRhi render target.

A host surface implements mne::viz::qt::BrainViewHost and forwards its events and frames: mne::viz::qt::BrainView (a QRhiWidget) and mne::viz::qt::BrainWindow (a QWindow owning its own QRhi).
