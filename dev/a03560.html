Detailed Description

Visualization without a GUI toolkit: figures as display lists (figures/), the logic of the trace and brain views (views/), GPU frame descriptions with a software renderer (gpu/), settings panel descriptions (forms/) and view models (models/). Toolkit backends such as mne_viz_qt render them.
