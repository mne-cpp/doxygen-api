Detailed Description

Viewport subdivision holding its own camera, projection, and scissor rectangle.

Encapsulates all per-view state for a single viewport (single view or one pane in multi-view).

The class stores shader, surface type, overlay mode, visibility flags, and, through its toolkit-neutral mne::scene::PaneCamera base, the zoom, pan, camera rotation and view preset — everything that can differ between two viewports showing the same scene.
