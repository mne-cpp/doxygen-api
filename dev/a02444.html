Houses every class that round-trips an Elekta/Neuromag FIFF file: the stream layer (mne::FiffStream, mne::FiffTag, mne::FiffDirNode, mne::FiffDirEntry), the measurement metadata (mne::FiffInfo, mne::FiffChInfo, mne::FiffCoordTrans, mne::FiffId, mne::FiffDigPoint), the data containers (mne::FiffRawData, mne::FiffEvoked, mne::FiffEvokedSet, mne::FiffCov, mne::FiffProj, mne::FiffCtfComp, mne::FiffNamedMatrix, mne::FiffSparseMatrix) and the convenience facade FIFF. Surface-level parity with mne.io.fiff in MNE-Python.

FIFFSHARED_EXPORT marks the public symbols: exported when building the shared library, imported by its clients, and empty in a static build (STATICBUILD).
