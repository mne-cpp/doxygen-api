The implementation converts MnaDataKind and MnaPortDir through the canonical string helpers from mna_types.h so the on-disk vocabulary stays single-source. Stream-related fields (stream_protocol, stream_endpoint, stream_buffer_ms) and cache-related fields (cached_result_path, cached_result_hash) are only written when non-default so simple file-based projects stay compact, and any unknown attribute is shovelled into extras to keep the round trip lossless across mne_mna versions.
