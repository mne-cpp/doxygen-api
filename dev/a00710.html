Detailed Description

Graph container that stores the result of one functional-connectivity metric as nodes (sources/sensors) and weighted edges (channel-pair couplings).

mne::Network is the common output type returned by every estimator in mne_connectivity. Each mne::NetworkNode carries a 3D position (sensor coordinate for sensor-space metrics, source vertex for source-space metrics) and the indices of its incident edges, and each mne::NetworkEdge stores the full per-frequency weight matrix together with the scalar band-averaged weight used for thresholding and display. The same container is used for symmetric metrics (coherence, PLV, PLI/wPLI/dwPLI, imaginary coherence, correlation, cross-correlation) and for the directed metrics (Granger Causality, DTF, PDC); directionality is encoded by treating (i, j) and (j, i) as distinct edges.

Nodes and edges are stored contiguously by value, so a Network is a regular value type: copies are deep and independent.
