Detailed Description

The BabyMEG acquisition server: its channel description and data packages, over TCP or from a simulator.

Every message is a 4-character command, a big-endian 32-bit length and that many bytes. On its command port the server answers "INFO" with the channel description, a text "INFO:<channels>:<samples>:<rate>:" followed by one "<name>|<scale>,<r0>,<ex>,<ey>,<ez>,<coil type>,<cal>,<gain>;" per channel. On its data port it answers "DATA" with one "DATR" package, a format digit (the bytes per value) and big-endian floats, sample after sample, and "QUIT" with "QUIT", which the client acknowledges with "QREL". A physical value is raw * cal / gain.
