lsl://NAME opens the LSL stream called NAME (or the first stream matching type= or source_id=) as a device with one input stream. It uses only the in-tree mne_lsl implementation, which speaks the LSL protocol (discovery, data protocol 1.10, full info, time correction) with any LSL outlet, liblsl's included; liblsl is not loaded. AcqDeviceDescription::backendVersion is "in-tree".

Samples keep the stream's format (float32, double64, int32, int16; int8 is widened to int16 and int64 is read as double), and channel names, kinds and units come from the stream description (desc/channels/channel with label, type and unit), falling back to the stream type and "TYPE n" names. The clock model maps samples to LSL timestamps plus time_correction(), refreshed every second. Irregular-rate and string (marker) streams are not supported yet.
