Detailed Description

Widgets-free QWindow host of the GPU raw-data channel trace view.

ChannelWindow creates its own QRhi, swap chain and render pass descriptor, renders a mne::viz::qt::ChannelRhiRenderer frame on every expose and update request and forwards its input events to the renderer. It only needs QtGui. A Qt Widgets application embeds it with createWindowContainer(channelWindow, parent).
