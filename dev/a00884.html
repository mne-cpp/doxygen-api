mne::write_matrix and mne::read_matrix round-trip any dense Eigen expression through plain text, one row per line, so intermediate results can be compared with NumPy (numpy.loadtxt and numpy.savetxt read and write the same layout) and reference data can be checked into a test-data repository. Values are written with enough digits to read back bit-identical; lines containing # are comments.

// Plain text, one row per line: numpy.loadtxt reads it, and values read back bit-identical
const std::filesystem::path matrixPath = std::filesystem::temp_directory_path() / "ex_math_matrix.txt";
MatrixXd matrix(2, 3);
matrix << 0.1, -2.0 / 3.0, 3.25, 0.0, 1e-6, 42.0;
mne::write_matrix(matrix, matrixPath, "example matrix");
MatrixXd readBack;
mne::read_matrix(readBack, matrixPath);
