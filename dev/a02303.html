Each dipole becomes one instance in the mne::viz::DipoleObject arrow mesh: position drives the instance translation, orientation the rotation, goodness-of-fit the colour mapped through the active dipole colormap. Toggling visibility on this item simply hides the corresponding instance range in the GPU buffer.
