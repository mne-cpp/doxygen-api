Detailed Description

Surface and SurfaceClient connect a view of mne_viz to the window of a backend.

A backend hosts a view in a window: it measures the window, translates its input to the events of views/input_event.h, asks the view for a GpuFrame and executes it with its renderer. The view in turn asks the host for a clock, a redraw and a pointer shape. Surface is the host's side of that contract, SurfaceClient the view's, so any view runs in any backend (Qt, SDL, ...) without knowing which.
