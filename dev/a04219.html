Detailed Description

Runs tasks on a fixed set of worker threads.

parallel_for() and parallel_map() block until done, and the calling thread works through the range too, so they may be nested or called from a task of the same pool without deadlocking.

const std::vector<int> channels = {0, 1, 2, 3};
const std::vector<double> power = ThreadPool::global().parallel_map(channels, [](int ch) { return 0.5 * ch; }); // in order
auto background = ThreadPool::global().submit([] { return 42; });
