Detailed Description

Internal shared state of one stream ring; not installed.

Concurrency protocol:

  • The single producer publishes samples with a seq_cst store of committed. Before it writes into the ring it announces the highest sample index it may touch in reserved, followed by a full fence, so a reader that validates a view by loading reserved after an acquire fence detects every overwrite.
  • Each reader slot is written only by its reader. The producer touches reader slots only to wake readers that announced a wait (waiters > 0) and, for output streams, reads the gating reader's position.
  • Records (events, segment headers) use the same reserve/publish scheme as samples.
  • Blocking uses one binary semaphore per waiter and a Dekker handshake on seq_cst atomics; nothing on the data path takes a mutex or allocates.
