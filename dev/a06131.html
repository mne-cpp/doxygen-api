Detailed Description

Ordered list of MNEEpochData objects sharing a common measurement info.

Epoch data list, which corresponds to a set of events

QFile rawFile(data + "/MEG/sample/sample_audvis_trunc_raw.fif");
const FiffRawData raw((data + "/MEG/sample/sample_audvis_trunc_raw.fif").toStdString());
const FiffEvents events = FiffEvents::find_events(raw).value(); // rising edges on STI 014
// Epochs of event 1 from -100 to 300 ms, no rejection
MNEEpochDataList epochs = MNEEpochDataList::readEpochs(raw, events.events, -0.1f, 0.3f, 1, {});
const MNEEpochData& firstEpoch = *epochs.front();
FiffEvoked evoked = epochs.average(raw.info, raw.first_samp, raw.last_samp);
// Peak-to-peak rejection like mne.Epochs(reject=...): flagged epochs stay in the list with bReject set
const std::map<std::string, double> reject{{"grad", 1.6e-14}, {"eeg", 1.6e-8}};
MNEEpochDataList checked = MNEEpochDataList::readEpochs(raw, events.events, -0.1f, 0.3f, 1, reject);
QList<int> keptEpochs;
for (int i = 0; i < std::ssize(checked); ++i) {
if (!checked.at(i)->bReject) {
keptEpochs << i;
}
}
const bool firstIsClean = !MNEEpochDataList::checkForArtifact(firstEpoch.epoch, raw.info, reject);

averageCategories

Multi-category offline averaging. Reads epochs from raw data for multiple event types and returns an FiffEvokedSet with one FiffEvoked per category. Ported from average.c (MNE-C).

Parameters
[in]rawThe raw data.
[in]eventsEvent matrix (nEvents x 3): [sample, before, after].
[in]eventCodesList of event codes, one per category.
[in]commentsList of category names/comments, one per category.
[in]tminStart of epoch relative to event (seconds).
[in]tmaxEnd of epoch relative to event (seconds).
[in]mapRejectRejection thresholds (key = channel type string, value = threshold).
[in]baselineBaseline interval [from, to] in seconds. If from==to, no baseline correction.
[in]projApply SSP projection vectors (optional, default = false).
Returns
FiffEvokedSet containing one FiffEvoked per category.
