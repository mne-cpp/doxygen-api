AbstractTreeItem centralises the data roles every scene object needs (VisibleRole, TransformRole, ColorRole, AlphaRole) so the renderer can read render state directly from the model without per-type if-chains. The AbstractTreeItem::ItemType "ItemType" enum drives type-safe down-casts at the few sites that need them (picking, persistence).
