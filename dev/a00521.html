The producer (e.g. MNE Scan's file writer) calls FIFFLIB::FiffFileSharer::copyRealtimeFile, which copies a recording into the shared directory as realtime_file<N>_raw.fif and closes its raw block so it is a complete FIFF file. The consumer (e.g. MNE Analyze) calls FIFFLIB::FiffFileSharer::initWatcher and receives newFileAtPath once the next file has been written.
