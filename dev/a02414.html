Detailed Description

TraceViewClient runs the raw-data trace view in any backend's window.

The trace view needs more than TraceView itself: an animator for its scroll and zoom animations, markers, a style, text metrics and a frame builder that turns it into GPU frames, all wired so that zooming invalidates the vertex cache and animations ask the host for frames. TraceViewClient does that wiring once, as a SurfaceClient, so a backend only forwards its window's input and executes the frames.
