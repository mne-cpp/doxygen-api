Detailed Description

TextMetrics measures text for layout; ApproximateTextMetrics does so without fonts.

Figures size margins and legends by their text. A window-system backend measures with its real fonts (the QPainter backend with QFontMetrics); headless rendering and golden tests use ApproximateTextMetrics, which gives the same numbers on every platform.
