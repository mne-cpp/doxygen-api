Detailed Description

Top-level QRhiWidget that hosts the 3-D scene, drives camera interaction and exposes the multi-view + live-marker API.

BrainView is the public face of mne_viz_qt — the QWidget that any host application embeds to get an interactive cortical / sensor / source scene. It is a thin QRhiWidget host around mne::viz::qt::BrainViewCore, which connects mne::viz::qt::BrainTreeModel data changes to scene rebuilds, feeds the Qt mouse / wheel / key events to the toolkit-neutral camera, input and pane layout of mne_viz (mne::viz::BrainViewInteraction), paints the 2-D overlay and delegates the actual drawing to mne::viz::qt::BrainRenderer. mne::viz::qt::BrainWindow hosts the same core in a QWindow.

Live overlays such as digitizer tracker markers or AR avatars are exposed through the lightweight mne::viz::qt::LiveMarker struct so the host GUI can spray transient annotations on the scene without going through the tree model.
