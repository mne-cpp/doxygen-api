Detailed Description

Instanced connectivity-graph renderable: node spheres and edge cylinders coloured by weight through a named colormap.

NetworkObject mirrors the mne::disp::DipoleObject instancing pattern but splits the scene into two meshes — nodes (spheres) and edges (cylinders) — each with its own vertex / index / instance buffer triple. The node mesh re-uses the dipole instance layout for shader compatibility (model + colour + isSelected), so a single pipeline serves both renderables.

setColormap selects the palette (Viridis, Hot, Jet, ...) used to map edge weight to RGBA; setThreshold prunes edges and nodes below a normalised cut-off and regenerates the instance stream without touching the underlying mne::Network.
