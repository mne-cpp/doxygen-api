Detailed Description

Sources for vendor EEG amplifiers, each with a simulator of its wire format.

Each amplifier is a URI scheme of AcqDeviceRegistry. The streams carry the amplifier's own sample format (BrainAmp: 16-bit channels in steps of the chosen resolution, then the marker word, at 5 kHz; TMSi: a 32-bit integer per channel with the SDK's gain, offset and exponent; g.USBamp: a float per channel in microvolts; eego: a double per channel in volts), so readers see exactly what the driver delivers. simulate=1 replaces the vendor driver with a simulator that digitises a synthetic:// session in that format, which runs on every platform and needs no hardware; seed, realtime and duration work as for synthetic://. The real driver interfaces are Windows-only: BrainAmp's is compiled when the vendor's SDK header is found (CMake variable MNE_BRAINAMP_SDK_DIR), TMSi's and g.USBamp's load the vendor's system DLL at run time, eego's loads the eego SDK library on Windows and Linux. Without them, opening without simulate=1 fails with BackendUnavailable.

mne::registerBrainAmpScheme(); // needed only where static linking drops the library's initialiser
auto device = mne::AcqDevice::open("brainamp://?simulate=1&channels=32");
