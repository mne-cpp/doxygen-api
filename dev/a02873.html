mne::MNESourceSpaces wraps the list of mne::MNESourceSpace objects that form a complete cortical source space as written by mne_setup_source_space (one entry per hemisphere, or additional entries for discrete / volume source spaces). It is the natural input to mne::MNEForwardSolution and mne::MNEInverseOperator and feeds the 3D rendering pipeline via mne::MNEHemisphere. Provides FIFF read/write at the file level so callers do not have to walk the block tree by hand.
