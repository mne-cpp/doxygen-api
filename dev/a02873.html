Detailed Description

JSON values, arrays, objects and documents in standard C++, the counterpart of Qt's JSON classes.

JsonValue, JsonArray, JsonObject, JsonDocument and JsonParseError follow QJsonValue, QJsonArray, QJsonObject, QJsonDocument and QJsonParseError call for call, so porting is mostly a rename. The differences are:

  • Text is UTF-8: strings are std::string and std::string_view instead of QString.
  • Getters that return arrays, objects and strings return references and views instead of copies; they stay valid while the value they come from is neither changed nor destroyed.
  • Integers are kept as std::int64_t and doubles as double, so 64-bit integers keep every digit. As in Qt 6, type() reports Double and is_double() is true for both; is_integer() tells them apart.
  • JsonObject keeps its members in a vector sorted by key, which gives Qt's key order, O(log n) lookup and one allocation per object instead of one per member. Its elements expose key() and value(), and they also decompose into structured bindings: for (const auto& [key, value] : object).

Nothing throws on malformed input or missing data: parsing reports a JsonParseError, and a missing key or an index out of range yields an undefined value, like Qt.

Incremental parsing of streams, e.g. NDJSON from a socket, is in base/json_stream_parser.h.
