Detailed Description

High-level driver for sequential equivalent-current-dipole (ECD) fitting at every time point of an evoked or raw recording.

INVLIB::InvDipoleFit orchestrates the full mne-c mne_dipole_fit pipeline: it consumes a populated INVLIB::InvDipoleFitSettings, builds the forward-model workspace via INVLIB::InvDipoleFitData, generates the initial-guess grid via INVLIB::InvGuessData, and then fits one ECD per requested time bin returning the result as an INVLIB::InvEcdSet. Refactored from fit_dipoles.c / dipole_fit_setup.c (MNE-C) while preserving the sphere-model and BEM forward-model code paths used by the original mne-c tooling.
