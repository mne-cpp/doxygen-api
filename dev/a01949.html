Detailed Description

polhemus:// : Polhemus Fastrak / FastSCAN digitizers on a serial port, or their simulator.

Date

One input stream "poses" with a frame per update of all stations: for each station S its position "S X", "S Y", "S Z" in metres and its orientation quaternion "S QW", "S QX", "S QY", "S QZ". A station not seen yet reads NaN. The digitizer stops its continuous output while the stylus button is pressed; a pause of the stream becomes a frame that repeats the last poses with event code 1, and the output is started again.
