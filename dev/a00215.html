Detailed Description

brainflow:// : any board BrainFlow supports, through BrainFlow's library when it is installed.

The target is a BrainFlow board id or name (synthetic, cyton, ...); the parameters are BrainFlow's input parameters (serial_port, ip_address, ...). One input stream "eeg" carries BrainFlow's rows as channels, a double each in BrainFlow's units: microvolts for EEG, EMG, ECG and EOG (scale 1e-6 to volts), degrees Celsius for temperature, seconds since 1970 for the timestamp row. The timestamp row is the device clock, and a nonzero marker row value is an event at that sample.
