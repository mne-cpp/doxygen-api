Detailed Description

The mne_rt_server protocol: its command port and its data port, over TCP or from a simulator.

The command port takes text commands, e.g. "measinfo 3", each framed as a 16-bit block size and a string of a 32-bit byte length and UTF-16 characters, all big-endian; the replies have the same form. The data port sends FIFF tags, big-endian as in FIFF files: the measurement info (FIFFB_MEAS_INFO) on "measinfo", then FIFFB_RAW_DATA with FIFF_DATA_BUFFER tags of calibrated floats, sample after sample, from "start" to "stop".
