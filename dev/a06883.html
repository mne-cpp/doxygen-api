Detailed Description

Renderable dipole arrow set with instanced GPU rendering.

Renderable dipole object that builds instanced arrow geometry from an InvEcdSet and provides its CPU streams for instanced rendering.

InvEcdSet dipoles;
InvEcd strong;
strong.rd = Vector3f(0.0f, 0.0f, 0.05f);
strong.Q = Vector3f(0.0f, 0.0f, 20e-9f);
InvEcd weak;
weak.rd = Vector3f(0.03f, 0.0f, 0.05f);
weak.Q = Vector3f(10e-9f, 0.0f, 0.0f);
dipoles.push_back(strong);
dipoles.push_back(weak);
DipoleObject dipoleGlyphs;
dipoleGlyphs.load(dipoles); // one cone per dipole, scaled by moment
float dipoleDistance = 0.0f;
const int pickedDipole = dipoleGlyphs.intersect(Vector3f(0.03f, 0.0f, 0.2f), Vector3f(0.0f, 0.0f, -1.0f), dipoleDistance);
