MultiView is the top-level layout primitive used by every MNE-Scan plugin GUI: it inherits QMainWindow purely to gain the dock infrastructure, lets callers add named views through addWidgetTop / addWidgetBottom and persists / restores its dock geometry via QSettings. Views are added as mne::disp::MultiViewWindow instances so the user can detach, retab and stack them freely.
