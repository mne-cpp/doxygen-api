Each converter is one loop nest per (format, destination type), instantiated from templates: the format is a compile-time parameter, so the inner loops over channels and samples contain no branch on it and the compiler vectorises them. Blocks of kBlock samples keep source and destination of a block in cache when the destination is transposed relative to the ring. The library is built with floating-point contraction off, so the documented arithmetic (multiply, then add, no FMA) holds on every target.
