Detailed Description

Test convenience layer on top of mne::PythonRunner for cross-validating MNE-CPP results against MNE-Python.

Built on mne::PythonRunner, this helper adds what test code needs: an is_available() probe, has_package() lookups so a test can announce that it needs e.g. sklearn, and eval shorthands that run a snippet and parse its stdout into a number, vector or matrix.

The helper is independent of any test framework: a test decides itself whether to skip or fail when is_available() is false, and is_python_required() tells it whether CI demands Python (MNE_REQUIRE_PYTHON=true).
