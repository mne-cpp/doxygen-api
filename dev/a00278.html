A FIFF file is a flat tag stream bracketed by FIFFB_BLOCK_START / FIFFB_BLOCK_END markers. FIFFLIB::FiffDirNode is the tree the stream parser produces from those brackets: each node owns its block kind, its FIFFLIB::FiffId, the list of FIFFLIB::FiffDirEntry records that live directly inside its block, and a list of child FIFFLIB::FiffDirNode sub-blocks. Together with the random-access directory at the tail of the file this lets every downstream reader (FIFFLIB::FiffRawData, FIFFLIB::FiffEvoked, FIFFLIB::FiffInfo, FIFFLIB::FiffCov, ...) navigate to its block of interest with one call to FiffDirNode::dir_tree_find rather than rescanning the tag stream.

Mirrors the dir_tree object returned by mne.io.tree.dir_tree_find in MNE-Python so the same FIFFB_* search patterns can be used in both implementations.
