241 //=========================================================================================================
242 // Optical path calibration — determine the microscope optical axis
243 // relative to the tracker sensor.
244 //
245 // Workflow:
246 // 1. Move the OPMI to a position, aim at a point on the head surface,
247 // mark the focus point with the stylus pen → capture_optical_calib_sample().
248 // 2. Repeat at 2–3 different positions / focal distances.
249 // 3. Call solve_optical_calibration() to fit a 3D line through the focus
250 // points in the tracker's local frame, yielding the optical axis
251 // direction and the optical center offset from the tracker.
252 //=========================================================================================================
253
