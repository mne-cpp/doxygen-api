QuickControlView is a mne::disp::DraggableFramelessWidget that owns a QTabWidget into which application code can drop arbitrary mne::disp::AbstractView panels grouped by name. It is the floating settings sidebar shown next to MNE-Scan plugin widgets, supports opacity, transparency and "pinned" behaviour, and persists the current tab through QSettings.
