Like std::filesystem, every reader comes in two forms: one that throws, for compact code that cannot continue without the data (FiffCov cov(path)), and one that returns Expected<T>, for code that handles the failure (if (auto cov = FiffCov::read(path)) ...). Both carry the same Error, whose message names the file.
