MNA structs convert their members with to_json() / from_json() and to_cbor() / from_cbor(). Apart from embedded file data (byte strings) and the project dates (tag 0), the CBOR form of every MNA struct holds the same keys and values as its JSON form, so those structs encode CBOR through their JSON.
