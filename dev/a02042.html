Detailed Description

AcqBackend: the interface a device, file or network backend implements behind an AcqDevice.

Users hold an AcqDevice; backend authors derive from AcqBackend. While opening, a backend creates its input streams (it gets their writers) and output streams (it gets their gating readers). Between start() and stop() it runs its own acquisition/output thread, interrupt handler or DMA callback. AcqDevice owns the backend and enforces the state machine, so a backend only implements transitions.
