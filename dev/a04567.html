Detailed Description

Incremental JSON parser for real-time streams: feed bytes as they arrive, get documents as they close.

The stream holds root objects or arrays back to back, with or without whitespace in between, which covers NDJSON (one document per line) and concatenated JSON ({"event":1}{"event":2}). Every root that closes is either

  • queued for take_document(), the default,
  • passed to the callback set with set_document_callback(), or
  • reported token by token to the JsonHandler set with set_handler(), without building any JsonDocument.

Memory is bounded by Options: nesting depth, the bytes of one string or number held between chunks, and the bytes of one document. On malformed input feed() returns false, error() tells why and where, and the parser ignores input until reset(). Nothing throws, apart from std::bad_alloc and exceptions thrown by callbacks.

JsonStreamParser stream; // NDJSON from a socket, split anywhere
std::vector<double> latencies;
stream.set_document_callback([&](JsonDocument&& event) { latencies.push_back(event["latency"].to_double()); });
for (const std::string_view packet : {"{\"latency\":1.5}\n{\"lat", "ency\":2", ".25}\n{\"latency\":3}"}) {
if (!stream.feed(packet)) { // malformed input: report and resynchronize
Log::warning("bad JSON at byte {}: {}", stream.error().offset, stream.error().error_string());
stream.reset();
}
}
