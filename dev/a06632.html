Detailed Description

This defines a source space.

Implements the MNE Source Space (Replaces typedef mneSurfaceOrVolume mneSourceSpace; struct of MNE-C mne_types.h).

// A FreeSurfer surface with its curvature and the volume geometry from the file footer
const auto white = MNESourceSpace::load_surface((data + "/subjects/sample/surf/lh.white").toStdU16String(), (data + "/subjects/sample/surf/lh.curv").toStdU16String());
const MNEVolGeom& geometry = *white->vol_geom; // sizes and centre converted to metres
// Drop sources outside the inner skull or closer than 5 mm to it (mne make_forward_solution(mindist=5))
std::vector<std::unique_ptr<MNESourceSpace>> spaces;
MNESourceSpace::read_source_spaces(srcPath.toStdU16String(), spaces);
const FiffCoordTrans mriHeadT((data + "/MEG/sample/all-trans.fif").toStdU16String(), FIFFV_COORD_MRI, FIFFV_COORD_HEAD);
MNESourceSpace::filter_source_spaces(0.005f, (data + "/subjects/sample/bem/sample-5120-bem.fif").toStdU16String(), mriHeadT, spaces, nullptr, true);
