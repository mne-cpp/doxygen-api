Detailed Description

SoftwareRenderer executes a GpuFrame on the CPU, without a GPU or a window system.

The software backend of the GPU frame description: it rasterizes the draws of a GpuFrame into an RGBA image with depth testing, culling and blending, and runs C++ implementations of the shaders, so views render headless, e.g. for golden-image tests, command-line tools or a host without GPU access.
