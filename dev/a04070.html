Detailed Description

Head–device coregistration engine driven by a Polhemus Fastrak.

It takes the station poses and stylus button presses of a polhemus:// stream (on_pose(), on_button()) and maintains:

  • A continuously updated device-to-world transform (from the tracker station + user-supplied calibration offset).
  • An AcquiredPoints store filled by explicit capture calls or automatically on pen-button press.
  • The computed head–device transform after compute_registration.

Events (new poses, button presses, calibration progress) reach the caller through the callbacks of a Listener; a Qt application forwards them as signals.

PolhemusCoregistration coreg; // station 1 = pen, station 2 = head tracker
// Model fiducials are the pen fiducials turned 90 deg about z and moved 5 cm in x; the registration must find that transform
const Eigen::Affine3f truth = Eigen::Translation3f(0.05f, 0.0f, 0.0f) * Eigen::AngleAxisf(0.5f * static_cast<float>(EIGEN_PI), Eigen::Vector3f::UnitZ());
const FiducialId fiducials[] = {FiducialId::NAS, FiducialId::LPA, FiducialId::RPA};
std::vector<Eigen::Vector3f> penAt;
constexpr std::size_t kWidth = 14;
while (penAt.size() < 3) {
auto view = reader->lease(1, 2s);
if (!view) {
break;
}
const AcqBlockView& block = **view;
std::vector<float> frames(kWidth * block.sampleCount());
if (!decode(block, AcqMatrixRef<float>::columnMajor(frames.data(), kWidth, block.sampleCount())).ok()) {
break;
}
for (std::size_t i = 0; i < block.sampleCount(); ++i) {
const float* f = &frames[i * kWidth];
for (int station : {1, 2}) {
const float* p = f + (station - 1) * 7;
coreg.on_pose(station, Eigen::Vector3f(p[0], p[1], p[2]), Eigen::Quaternionf(p[3], p[4], p[5], p[6]));
}
for (std::size_t e = 0; e < block.events().size(); ++e) {
if (block.events()[e].sample == block.firstSample() + i && penAt.size() < 3) { // a stylus button press
const FiducialId id = fiducials[penAt.size()];
coreg.capture_current_pen_position_as_fiducial(id);
penAt.push_back(coreg.pen_position());
coreg.set_model_fiducial(id, truth * coreg.pen_position());
}
}
}
}
device->close();
const bool registered = penAt.size() == 3 && coreg.compute_registration();

Fine-adjust the optical axis so it passes through a known world-frame point (e.g. the probe tip touched with the stylus).

The correction rotates m_opticalAxisLocal in the tracker body frame so that a ray from the optical center would pass through targetWorldPos at the current tracker pose.

Returns

◆ capture_objective_center()

bool PolhemusCoregistration::capture_objective_center ( )

Capture the current pen position as the objective lens center.

Touch the pen stylus to the center of the OPMI objective lens while the tracker is live. The point is stored in the tracker's local frame and used by the solver as a direct measurement of the optical center, replacing the sphere-distance constraint.

Returns
true on success, false if pen or tracker data unavailable.

void mne::PolhemusCoregistration::set_axis_mirror ( bool mirror_x,
bool mirror_y )
inline

Negate X and/or Y of incoming Polhemus positions.

The Polhemus Fastrak coordinate system depends on the physical placement and orientation of the transmitter. When the transmitter is oriented such that its axes are mirrored relative to the expected neuroscience convention, enable the corresponding mirror flags here.

Parameters
[in]mirror_xTrue to negate the X coordinate of incoming positions.
[in]mirror_yTrue to negate the Y coordinate of incoming positions.

◆ set_known_tracker_to_objective_distance()

void mne::PolhemusCoregistration::set_known_tracker_to_objective_distance ( float metres)
inline

Set the known perpendicular distance from tracker sensor to the objective center (metres).

When nonzero, the solver constrains the optical center to lie at this distance from the tracker origin, vastly improving accuracy. Default: 0.200 m (~200 mm for ZEISS Kinevo). Set to 0 to disable.

Parameters
[in]metresTracker-to-objective distance in metres; 0 disables the constraint.
