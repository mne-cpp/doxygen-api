Renderable cortical / BEM mesh: CPU geometry, colour and annotation streams for the renderer.

BrainSurface is the core 3-D primitive of disp3D. It owns the CPU streams the renderer uploads: geometry (DISP3DLIB::VertexData, position and normal), packed-ABGR colour, packed-ABGR annotation colour and the triangle indices. Each stream has its own generation, so a source-estimate frame re-uploads only the 4-byte colour stream.

Per-vertex colour is computed once on the CPU from one of four sources selected by DISP3DLIB::VisualizationMode — flat base colour, FsAnnotation parcellation, scientific curvature shading (Lambertian ambient + sulcal darkening), or a source-time-course value mapped through the active colormap — then packed into the second colour slot so a single fragment shader covers every mode by blending the two colour streams.

The class accepts geometry from a FSLIB::FsSurface, an MNELIB::MNEBemSurface or raw Eigen matrices, and can carry a BrainSurface::TissueType "TissueType" tag so the renderer knows whether the mesh is a cortex, skin, skull or generic shell for alpha / lighting tuning.
