FwdSettingsView exposes the parameters needed by the mne_fwd forward-model recomputation: paths to BEM and source-space files, EEG sphere / individual model choice, MEG / EEG enable flags and a Recompute trigger. The panel also displays current model status (loaded BEM, dipole count, sensor count) so the user can verify the inputs before launching the heavy computation.
