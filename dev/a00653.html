Detailed Description

Widgets-free QRhi renderer and input handler of the raw-data channel trace view.

ChannelRhiRenderer is the Qt side of the raw-trace view: it converts input events and records the frames of mne::scene::TraceFrameBuilder into any QRhi render target with mne::disp::RhiFrameRenderer. The logic is Qt-free in mne_scene: mne::scene::TraceView (viewport, interaction state, HUD overlays), mne::scene::TraceFrameBuilder (trace vertices, textures and draws of a frame), mne::scene::TraceMarkers (annotation, event and epoch overlay) and mne::scene::ViewAnimator (scroll and zoom animations). It only depends on QtCore and QtGui: a host (the QRhiWidget mne::disp::ChannelRhiView or the QWindow mne::disp::ChannelWindow) implements mne::disp::ChannelRhiHost, forwards its input events and calls renderFrame().
