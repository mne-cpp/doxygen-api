Detailed Description

Manager that wires real-time sensor data into the scene: owns the data controller, the field mapper and the target surface.

RtSensorStreamManager bridges the streaming side (sensor packets arriving on a worker thread) and the rendering side (per-vertex colour updates on the target head / helmet surface). It owns the mne::viz::qt::RtSensorDataController plus the dense MEG / EEG mapping matrix produced by mne::viz::SensorFieldMapper and forwards new colour buffers to the bound mne::viz::BrainSurface on every frame.
