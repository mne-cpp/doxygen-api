◆ decimate_trace()

std::vector< float > mne::scene::decimate_trace ( std::span< const float > samples,
int pixel_width,
Detrend detrend = Detrend::None )

Turns a window of samples into trace vertices (interleaved x, y with x the offset from the first sample).

Up to two samples per pixel every sample is a vertex. Beyond that the window is split into pixel_width bins, each drawn as its maximum and then its minimum at the bin start, so that a line strip draws the min/max envelope (2 vertices per pixel).

Parameters
[in]samplesThe window.
[in]pixel_widthPixels the window spans; nothing is returned if it is not positive.
[in]detrendTrend to subtract; for bins it is taken at the bin centre.
Returns
The vertices.
Since
3.0.0

Draws the view as an image would show it, into (0, 0, width, height) of canvas: the per-second bands and the grid (if style.grid), the annotations, the traces as polylines (clipped segments in red) and the event and epoch lines. The time span of view is kept at any canvas width; the traces are fetched from source at the canvas resolution.

canvas.set_pen(Pen{{50, 100, 150}, 1.5});
canvas.set_brush(Brush::solid({70, 130, 180}));
canvas.draw_rounded_rect({20, 20, 80, 50}, 6, 6);
canvas.set_pen(Color::black());
canvas.draw_text(Rect{0, 80, 200, 30}, Align::Center, "Hello scene");
const DisplayList figure = canvas.take();
// A plot: the same model a disp widget shows on screen
std::vector<double> x;
std::vector<double> y;
for (int i = 0; i < 100; ++i) {

y.push_back(std::sin(2 * 3.14159265358979 * 5 * x.back()));
