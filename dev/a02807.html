Detailed Description

Pre-processing front-end for HPI fitting — re-shapes raw MEG data, projectors and digitised coils into per-fit inputs.

mne::InvHpiDataUpdater isolates everything that has to happen before mne::InvHpiFit can run on a new measurement block: re-deriving the good-channel list from the FiffInfo, slicing the SSP projector to those channels, projecting the data buffer, lifting the digitised HPI coil positions out of the dig-point list and rebuilding the mne::InvSensorSet whenever the channel layout changes. The class caches the most recent state so consecutive HPI fits on the same configuration only re-run the steps that actually changed.
