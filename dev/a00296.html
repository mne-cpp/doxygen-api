Detailed Description

AcqDevice: an opened device, file or network endpoint with its input and output streams (control path).

Lifecycle: open() -> Opened -> start() -> Running -> stop() -> Stopped -> (start() again) ... -> close() -> Closed. stop() joins the backend threads (output streams emit their underrun fill from then on), close() releases the device, the destructor equals close(). A backend error moves the source to Failed; lastError() names it. Streams and readers obtained from a source stay valid after close() and report EndOfStream.
