Detailed Description

decode() native samples into caller-owned matrices and encode() matrices into output rings.

One memory pass: format conversion, layout transposition and per-channel scaling are fused and cache-blocked, written as fixed-width loops the compiler vectorises (no intrinsics, no Eigen, so the same code builds for embedded targets). Converters never allocate.

Arithmetic is defined, so results are bit-exact against the scalar reference used in the tests: float targets compute float(raw) * float(scale) + float(offset) without FMA contraction, double targets the same in double (use double for int32 data beyond 2^24). encode() computes (value - offset) / scale in double, saturates to the channel range and to the native type, and rounds to nearest, ties to even; NaN encodes as 0. Both count what they could not represent. Channels with AcqChannelInfo::digitalBits = d use raw = signExtend(low W-d bits) << d on decode (W = word width) and keep the top d bits untouched on encode (value quantised to W-d bits).

A channel range lets several threads convert disjoint channel blocks of the same view in parallel.
