Detailed Description

Viewport subdivision holding its own camera, projection, and scissor rectangle.

Encapsulates all per-view state for a single viewport (single view or one pane in multi-view).

The class stores shader, surface type, overlay mode, visibility flags, and, through its toolkit-neutral mne::viz::PaneCamera base, the zoom, pan, camera rotation and view preset — everything that can differ between two viewports showing the same scene.

// A pane's camera, shaders and layer visibility survive a restart through any SettingsStore
MemorySettingsStore viewSettings; // QtSettingsStore puts the same keys into a QSettings
SubView pane = SubView::defaultForIndex(2);
pane.surfaceType = "inflated";
pane.visibility.setObjectVisible("dipoles", false);
pane.save(viewSettings, "multi2_");
SubView restored;
restored.load(viewSettings, "multi2_");
