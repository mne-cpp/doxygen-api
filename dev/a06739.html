Detailed Description

Interactive FIR / IIR filter design GUI with a live magnitude / phase preview.

Lets the user pick filter type, design family (cosine, Hamming, Blackman, …), cutoff frequencies, transition bandwidth and tap count, then renders the resulting frequency response in an embedded FilterPlot and emits the FilterKernel as a filterChanged signal consumed by the rtprocessing chain.
