ECG detection finds cardiac R-peak events via bandpass filtering (5–40 Hz) followed by an adaptive threshold and local maximum search. If no dedicated ECG channel is present the algorithm falls back to a synthetic ECG derived from the MEG gradiometer channels.

EOG detection finds blink/saccade events by low-pass filtering (1–10 Hz) and applying an absolute amplitude threshold.
