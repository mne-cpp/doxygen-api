The producer (e.g. MNE Scan's file writer) calls mne::FiffFileSharer::copy_realtime_file, which copies a recording into the shared directory as realtime_file<N>_raw.fif and closes its raw block so it is a complete FIFF file. The consumer (e.g. MNE Analyze) calls mne::FiffFileSharer::new_files whenever it is told the directory changed, for instance by a file system watcher.
