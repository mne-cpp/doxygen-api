mne::FiffEvoked is one averaged response as written under a FIFFB_EVOKED block: the time axis (times, first, last), the (nchan × nsamples) data matrix, the baseline interval, the averaging kind (FIFFV_ASPECT_AVERAGE, FIFFV_ASPECT_STD_ERR, ...), the trigger comment, the number of averaged epochs (nave) and the associated mne::FiffInfo. Multiple mne::FiffEvoked objects belonging to the same recording (one per condition) make up a mne::FiffEvokedSet.

Drop-in counterpart of mne.Evoked in MNE-Python: the same kind / nave / comment / baseline semantics and the same channel-picking, projector-application and SSP behaviour.
