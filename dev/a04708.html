Detailed Description

Weighted, directional edge in a Network; carries per-frequency weights plus a band-averaged scalar.

Directed weighted edge between the nodes with indices source and target. Holds the full per-frequency weight matrix delivered by the metric, the frequency-bin window that reduces it to the scalar weight, and the active flag set by Network::set_threshold. For symmetric metrics the direction is a storage convention only.

NetworkEdge is a plain value type: copies are independent.

Network network("manual");
for (int i = 0; i < 3; ++i) {
network.add_node(positions.row(i).transpose());
}
network.add_edge(NetworkEdge(0, 1, MatrixXd::Constant(1, 1, 0.9))); // one weight per frequency bin
network.add_edge(NetworkEdge(1, 2, MatrixXd::Constant(1, 1, 0.2)));
