Detailed Description

Single measurement epoch or average within MNEMeasData.

Replaces *mneMeasDataSet / mneMeasDataSetRec from MNE-C mne_types.h. Holds the measured data matrix, optional projector / whitened / filtered copies, baseline values, and per-epoch metadata (number of averages, time range, etc.).

// MNE-C measurement container: data set 1 of the evoked file, MEG and EEG channels, time-major
std::unique_ptr<MNEMeasData> meas(MNEMeasData::mne_read_meas_data(aveFile.fileName().toStdU16String(), 1, nullptr, nullptr, {}, 0));
const MNEMeasDataSet& left = *meas->current;
const float meg0113 = left.data(180, 0); // t = 99.9 ms
meas->adjust_baselines(-0.2f, 0.0f);
VectorXf at100ms(meas->nchan);
const bool picked = left.getValuesAtTime(0.1f, 0.0f, false, at100ms) == 0; // linear interpolation between samples
