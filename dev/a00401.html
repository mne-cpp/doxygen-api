Most callers want to open a FIFF file and immediately get back a mne::FiffRawData (for "*-raw.fif"), a mne::FiffEvokedSet (for "*-ave.fif"), a mne::FiffCov (for "*-cov.fif"), or the appropriate combination without micromanaging mne::FiffStream and the directory tree. mne::FiffIO provides exactly that one-call facade: it sniffs the top-level FIFF blocks (FIFFB_RAW_DATA, FIFFB_EVOKED, FIFFB_MNE_COV, ...), invokes the matching specialized reader and exposes the results as ready-to-use shared pointers, with parity to the mne.io.read_raw_fif / mne.read_evokeds / mne.read_cov front-end of MNE-Python.
