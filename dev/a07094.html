Detailed Description

A settings panel: its fields in order and their values.

Numbers are clamped to their range and choices must be one of the field's, so the values are always valid. Listeners hear about every value that changes and every triggered action; structure listeners hear when fields change their range, choices, label or presence.

// A settings panel described once; any toolkit builds its widgets from it (disp::SettingsPanel for Qt)
SettingsForm form("Averaging");
form.add_int("trials", "Number of trials", 10, 1, 1000, 1, {}, "General");
form.add_bool("baseline", "Baseline correction", false, "Baseline");
SettingField from;
from.key = "baseline_from";
from.kind = SettingField::Kind::Int;
from.label = "From";
from.unit = " ms";
from.minimum = -1000;
from.maximum = 0;
from.group = "Baseline";
from.enabled_if = "baseline";
form.add(from);
int heard = 0;
form.add_listener([&heard](const std::string&, const std::optional<SettingValue>&) {
++heard;
});
form.set_value("trials", 5000);
