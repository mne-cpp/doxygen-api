This header collects the original MNE C library "analyze" type definitions that are used across the entire inverse library — not only by dipole fitting, but also by field mapping, overlay display, HPI processing, and general MEG/EEG data handling.

The types are C-style typedef'd structs (pointer-to-struct idiom) preserved from the MNE C code base for backward compatibility. New code should prefer modern C++ classes where possible; these definitions remain available for components that still rely on the legacy data layout.
